# OrangeHRM – Manual Testing Project

## Project Overview

This project focuses on manual testing of the **Admin – User Management** module of the OrangeHRM public demo application.

The objective was to understand the application, identify test scenarios, design test cases, execute tests, document actual results, and record issues observed during testing.

## Application Under Test

- **Application:** OrangeHRM
- **Environment:** OrangeHRM Public Demo
- **URL:** https://opensource-demo.orangehrmlive.com/
- **Module:** Admin → User Management
- **Testing Type:** Manual Testing

## Scope of Testing

The following functionalities were covered:

1. Admin page navigation
2. User Management page and UI verification
3. Username search
4. User Role and Status filters
5. Employee Name search
6. Reset functionality
7. Add User functionality
8. Mandatory field validations
9. Duplicate username validation
10. Edit User functionality
11. Username update
12. Password change and validation
13. User account status update

## Testing Activities

- Studied the application and its available modules.
- Explored the Admin – User Management functionality.
- Prepared application study documentation and exploration notes.
- Designed 38 test scenarios.
- Created 37 detailed test cases.
- Defined preconditions, test steps, test data, and expected results.
- Executed test cases and recorded actual results.
- Documented issues requiring further investigation and an additional validation observation.
- Prepared a test execution summary.
